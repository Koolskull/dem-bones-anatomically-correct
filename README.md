# Dem Bones, Named Right

The dry-bones song with every adult human bone named correctly. 206 bones. No foot bone, no leg bone, no head bone.

The lyrics are in [LYRICS.md](LYRICS.md). That file is the whole song, then a numbered list of all 206 bones.

The other markdown files in this repo are the same lyrics. Earlier drafts were placeholders that cut the song off. They are not placeholders anymore.
